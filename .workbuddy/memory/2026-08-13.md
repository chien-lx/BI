## Axhub Make 版本同步：git push/fetch 到 GitHub 超时

- **问题**：`git push -u origin main` / `git fetch` 到 github.com 超时（报错 "Failed to connect to github.com port 443" / "Command timed out"）。
- **根因**：运行环境注入了 `HTTPS_PROXY=http://127.0.0.1:58492`（系统代理）。该代理能通 example.com，但**无法隧道到 github.com**（返回 502 CONNECT tunnel failed）；而**直连 github.com 正常**（curl 直连 HTTP 200, ~0.75s）。git 继承该环境变量导致所有 github 操作走坏代理而超时。
- **临时解法**：`env -u HTTPS_PROXY -u HTTP_PROXY -u https_proxy -u http_proxy git ...` 直连推送成功（main: `95a0a51..df8e186` V1.06，fast-forward，无合并/无强制）。
- **永久修复（已应用）**：仓库内 `git config http.https://github.com.proxy ""`（仅作用于本仓库的 github.com，覆盖环境代理）。已验证此后 `git fetch origin` 无需手动 bypass 即成功。
- **认证**：`gh` 已登录 chien-lx（token 含 repo scope），git 通过 gh credential helper 取 token。
- **状态**：main 已与 origin/main 同步；`gh-pages` 仍 behind 1（非本次范围，未处理）。

## 修复：npm run dev 后首页卡在「管理服务正在启动...」

- **现象**：`npm run dev` 起来后，根页面常驻「可以通过 npx @axhub/make 启动管理页面。管理服务正在启动...」，管理 UI 打不开。
- **根因**：`vite-plugins/autoStartMakeServerPlugin.ts` 的 `resolveMakeServerStartCommand` 在 npx 分支拼出 `npx @axhub/make <projectRoot>`，但 `@axhub/make` CLI 不接受位置参数（报 `Unexpected argument` 直接退出），且缺 `--dev` 时后端 API 返回 502、`/api/health` 不就绪 → 客户端 `waitForAdminOrigin` 60s 超时判为「未就绪」。
- **修复**：npx 分支改为 `args = ['@axhub/make', '--dev']`（去掉位置参数 projectRoot，补 `--dev`）；cwd 已是 projectRoot，项目由客户端经 `/api/projects/make/register-existing` 注册。
- **验证**：重启后日志出现 `✅ Axhub Make server ready at http://localhost:53817` 与 `Registered Make`；`/__axhub/make-server/status` 返回 `ready:true`；dev 地址 http://localhost:51720/ 正常。
- **注意**：沙箱里 pgrep/pkill/lsof 对 node 进程权限受限，残留的 make 代理进程（如 5174/5199 的 502）杀不掉也不影响——自启服务默认走 53817，客户端按 `.admin-server-info.json`/状态接口定位，会忽略陈旧端口。

## 修复：查询组件交互与选中错乱

- **问题**：
  1. 查询组件选中后右侧显示的是「数据」面板，用户期望像 QuickBI 一样默认进入「样式」配置。
  2. 鼠标移入查询组件应出现编辑按钮，点击进入查询条件设置弹窗。
  3. 查询条件设置弹窗需要左侧条件列表（可添加/删除）、中间关联图表、右侧基础配置。
  4. 先添加查询组件再添加图表后，点击查询组件会错误显示成「柱状图」配置，且查询组件类型标签变成「柱状图」。
- **根因**：`packChart()` 在切换选中的非图表组件时，会把当前 `chartType` 状态（默认 `bar`）写入该组件，导致查询组件被覆盖成柱状图。
- **修复文件**：`src/prototypes/data-analysis-engine/pages/dashboard/config/index.tsx`
  1. `packChart()` 增加 `if (!existing || !isChartType(existing.type)) return null;`，仅打包真正的图表组件。
  2. 查询组件右侧面板增加「样式 / 数据」tab，默认「样式」；样式 tab 包含组件名称、数据源、位置尺寸、查询条件配置入口。
  3. 查询组件画布渲染增加 `hoveredWidgetId` 状态与悬浮编辑按钮（右侧蓝色竖条 + Settings2 图标），点击打开 `QueryConfigModal`。
  4. 重写 `QueryConfigModal`：三栏布局（左：查询条件列表 + 添加/删除；中：关联图表及字段 + 全选/清空；右：当前条件的基础配置：展示类型、时间粒度、筛选方式、默认值）。
- **验证**：TypeScript 类型检查无新增错误；浏览器自动化验证：查询组件选中后右侧显示「样式」tab、添加图表后再点击查询组件不错乱、`QueryConfigModal` 三栏布局正确显示 3 个可关联图表。
