## AI 智能助手（悬浮按钮 + 对话 + 管理后台）

- 新增模块：`components/AIAssistant/AIAssistantWidget.tsx`（可拖拽悬浮按钮、按钮本身收起/隐藏、右侧滑出对话面板、多会话管理）、`components/AIAssistant/retrieve.ts`（关键词+同义词召回、结构化答案）、`data/assistantManual.ts`（操作手册种子 22 条 + localStorage 读写 + 助手参数配置）、`pages/AssistantAdminPage.tsx`（超管专属：知识库文档查看/搜索/新建/编辑/删除/预览 + 参数配置）。
- 挂载点：`index.tsx` 的 AppShell 在已登录全屏页 / 常规布局分支渲染 `<AIAssistantWidget setPage />`，**登录页不渲染**；fixed 超高 z-index，所有页面与弹窗之上均可点。
- 悬浮按钮形态：仅保留**单个机器人头像按钮**（无文字、无书本图标），hover 时右上角浮现小「×」可收起按钮本身；收起态为右侧边缘的精致半圆小胶囊（蓝渐变、机器人图标、hover 显示展开箭头），localStorage 记住收起态。
- 对话面板：改为**从右侧推出**；顶部 header 与面板融为一体——浅蓝到白渐变背景，左侧机器人头像+标题/副标题，右侧「历史会话」下拉、最小化、关闭按钮，下方「Hi~ 今天想解决什么问题？」欢迎语 +「开启新对话」按钮；会话列表移入「历史会话」下拉面板，支持置顶/重命名/删除/切换。
- 会话数据：`localStorage` 持久化 `dae-assistant-sessions-v1`，支持新建/删除/重命名/置顶/切换会话。
- 管理入口：仅 `currentUser.isSuperAdmin` 时，Layout 右上角账号下拉显示「AI 助手管理」；对话面板内不再展示管理后台按钮（面向用户）。`assistant-admin` 已加入 `defineHashPageRoute` 与 project.json。
- 修复：widget 漏导入 `ChevronRight`；admin 页 `useHashPage` 路径修正；widget 初始 `pos` 的 SSR fallback 修正；移除 widget 的 `canManage` prop；tsc 对本次新增/改动文件 0 错（dataset/config、report/config 的 3 处报错为历史预存、与本次无关）。
- 演示：刷新 53817 → 右侧悬浮按钮可拖拽/收起；点击打开右侧面板，可新建会话、提问、查看结构化答案；超管从顶部下拉进「AI 助手管理」维护文档与参数。
